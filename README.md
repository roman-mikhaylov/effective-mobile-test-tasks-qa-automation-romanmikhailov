# effective-mobile-test-tasks-qa-automation-romanmikhailov
## Описание тестового задания

Данный репозиторий содержит мои решения тестовых заданий для позиции системного аналитика / QA Automation Engineer в компании Effective Mobile. Текст заданий предоставлен компанией и не публикуется здесь целиком; ниже приведено краткое пересказанное описание.

### Задание 1 (системный анализ ТЗ корзины)

По условию нужно было:

- найти и перечислить логические противоречия и недочёты в фрагменте ТЗ по корзине интернет-магазина;
- предложить переписанную, логически непротиворечивую версию этого фрагмента;
- сформулировать уточняющие вопросы продукт-менеджеру / бизнес‑заказчику по этому ТЗ.

В каталоге `-system-analysis/01-system-analysis` находятся:

- `README.md` — краткое резюме результатов анализа;
- `analysis.md` — список обнаруженных проблем в исходных требованиях с пояснениями;
- `fixed-spec.md` — предложенная согласованная версия требований к корзине;
- `questions.md` — перечень уточняющих вопросов к заказчику.

### Задание 3 (архитектура push-уведомлений)

По условию требуется спроектировать архитектуру системы push-уведомлений для мобильного приложения интернет-магазина «Петрушка Зеленая» с поддержкой сценариев:

- напоминание о брошенной корзине;
- уведомления об изменении статуса заказа;
- маркетинговые кампании;
- сервисные уведомления.

В каталоге `03-push-architecture` находятся:

- `docs/03-architecture-push.md` — подробное описание предложенной архитектуры;
- `diagrams/c4-push-architecture.mmd` и `*.png` — диаграммы C4 (контекст + контейнеры);
- `README.md` — краткое резюме решения и сценариев.
